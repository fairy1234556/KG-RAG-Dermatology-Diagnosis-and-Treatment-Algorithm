# KG-RAG 初步实验结果说明

## 1. 实验目的

本阶段实验的主要目的是验证知识图谱增强生成流程在 HAM10000 七类皮肤病辅助解释任务中的可行性。实验重点不是直接判断模型诊断准确率，而是考察系统生成内容是否能够基于知识图谱证据进行可追溯解释，以及生成结果是否能够保持证据一致性。

本实验围绕七类候选疾病分别构造代表性观察样例，包括黑色素瘤、黑色素细胞痣、基底细胞癌、光化性角化病/表皮内癌、良性角化样病变、皮肤纤维瘤和血管性皮损。每个样例均包含候选疾病、用户观察结果、知识图谱证据上下文和 KG-RAG 输出结果。

## 2. 实验样本设计

本实验共设置 7 个代表性测试样例，分别对应 HAM10000 数据集中的 7 个疾病类别。每个样例均采用相同的 KG-RAG Prompt 模板生成解释结果，以保证不同疾病类别之间的输出结构一致。

测试样例包括以下内容：

- CASE_001：基底细胞癌
- CASE_002：黑色素瘤
- CASE_003：黑色素细胞痣
- CASE_004：光化性角化病/表皮内癌
- CASE_005：良性角化样病变
- CASE_006：皮肤纤维瘤
- CASE_007：血管性皮损

每个样例的用户观察均围绕该疾病在知识图谱中的关键皮损表现或常见部位进行设计，例如基底细胞癌样例包含“珍珠样结节”“表面可见血管”“位于面部”等观察信息，黑色素瘤样例包含“形态不对称”“边界不规则”“颜色不均”等观察信息。

## 3. 评价指标

本阶段采用人工核查方式对 KG-RAG 输出结果进行初步评价，重点关注以下四类指标：

第一，Evidence Hit Rate，即证据命中情况。该指标用于观察用户输入中的关键症状、形态特征或部位信息是否能够在知识图谱证据中找到对应路径。

第二，Unsupported Claim Rate，即无依据生成情况。该指标用于检查生成结果中是否出现知识图谱证据上下文之外的医学判断、治疗建议或过度诊断结论。

第三，Path Consistency Score，即路径一致性。该指标用于判断生成内容中引用的证据路径是否与知识图谱中的疾病实体、关系类型和特征实体保持一致。

第四，Evidence Coverage Rate，即证据覆盖情况。该指标用于观察生成内容是否充分利用了知识图谱中的主要证据，包括主要皮损表现、常见部位、建议检查、鉴别诊断、风险提示和就医建议等内容。

由于本阶段尚未接入批量模型推理和自动化评分模块，因此上述指标暂时采用 high、medium、low、consistent 和 pass 等定性记录方式，后续可进一步扩展为量化评价。

## 4. 实验结果概述

从七个代表性样例的输出结果来看，KG-RAG 流程能够根据候选疾病从知识图谱中检索并组织相关证据，并将用户观察结果与图谱证据路径进行对应说明。大多数样例能够在“用户观察与证据匹配”部分明确说明观察表现与证据路径之间的关系。

在基底细胞癌样例中，用户观察到的珍珠样结节、表面可见血管和面部部位均能够对应到知识图谱中的表现关系和常见部位关系。该样例证据命中情况较好，生成内容能够围绕证据路径进行解释。

在黑色素瘤样例中，形态不对称、边界不规则和颜色不均能够对应到 ABCDE 相关证据，生成结果能够较好地体现高风险皮损需要进一步评估的谨慎表达。

在黑色素细胞痣样例中，色素性斑片、整体较对称和边界较规则能够与良性色素性皮损的均匀色素、边界清楚和对称性较好等证据形成对应关系，输出结果能够避免直接确诊，并提示需要观察皮损变化。

在光化性角化病/表皮内癌样例中，粗糙鳞屑性斑片和日晒暴露部位能够获得明确证据支持，同时系统能够引用癌前性质和进一步检查建议。该样例中用户观察信息相对较少，因此证据覆盖程度为中等。

在良性角化样病变样例中，蜡样或疣状表现、边界较清楚等观察能够对应到脂溢性角化病、日光性黑子等相关证据。但由于该类别本身包含多种良性角化样病变，类别内部异质性较高，因此输出结果需要保留“诊断不明确时进一步评估”的谨慎说明。

在皮肤纤维瘤样例中，坚实小结节和下肢部位能够支持候选疾病解释，但仍需要结合皮肤镜或病理检查进行进一步确认。

在血管性皮损样例中，红色或紫红色血管样表现能够对应到红色、蓝色或紫色丘疹、小腔隙和红色团块等证据，输出结果能够体现通常良性但快速生长、反复出血或诊断不明确时需要进一步评估的风险提示。

## 5. 初步结论

本阶段实验表明，知识图谱增强生成流程能够在七类 HAM10000 皮肤病样例中实现较为稳定的证据组织和辅助解释。与直接生成式回答相比，KG-RAG 输出能够显式呈现候选疾病、用户观察、证据路径、证据文本和来源之间的对应关系，从而提高输出内容的可追溯性和可解释性。

同时，实验结果也表明，知识图谱证据能够对生成内容形成一定约束，减少无依据医学判断的出现。各样例输出中均保留了“不能替代医生诊断”“需进一步评估”“给定证据不足”等谨慎表达，符合医学辅助解释任务对安全性和保守性的要求。

但本阶段实验仍存在一定局限。首先，测试样例数量较少，目前每个疾病类别仅设置一个代表性样例，尚不能充分反映复杂真实场景。其次，本阶段评价主要依赖人工核查，尚未形成自动化打分流程。再次，部分疾病类别内部构成较复杂，例如良性角化样病变和血管性皮损，单一标签可能包含多种不同病变类型，因此后续仍需进一步优化实体粒度和证据组织方式。

总体来看，本阶段已经完成从知识图谱构建、证据上下文生成、KG-RAG Prompt 构造到代表性样例输出与初步评价记录的闭环，为后续论文中的方法实现、实验设计和结果分析部分提供了基础材料。
