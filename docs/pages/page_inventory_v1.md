# V1.0 页面清单设计

## 1. 页面设计原则

V1.0 页面以医生端病例闭环为主，患者端为补充，后台服务于知识维护、实验复现和系统管理。

关键原则：

- 医生端优先展示病例、候选疾病、证据链和审核操作。
- 候选疾病排序必须展示得分构成，并明确不是患病概率。
- 图片仅作为病例资料展示，不出现自动分类结论。
- 患者端使用通俗语言，不展示最终诊断、处方、剂量、医生端完整候选评分或专业实验指标。
- 患者端不使用“低/中/高风险”表达，统一使用“需常规关注”“建议预约皮肤科评估”“建议尽快就医评估”。
- 研究人员角色 `researcher` 仅访问实验和研究相关模块，不访问未经授权的患者病例。
- 所有生成内容显示医学免责声明。
- 危险提示、证据不足和超范围提示清晰展示，但避免制造恐慌。

优先级说明：

- P0：V1.0 必须实现。
- P1：V1.0 应实现。
- P2：可后置或作为扩展。
