 # 图谱路径检索与证据排序规范 V1.0

## 1. 文档目的

本文档说明皮肤病知识图谱辅助诊断系统中图谱路径检索与证据排序模块的设计方案、输入输出、评分方法、验证样例及适用边界。

该模块位于语义锚点识别之后，负责根据候选疾病和用户观察结果，从知识图谱中检索相关证据路径，并按照可解释评分规则返回 Top-k 证据链。

本模块输出仅用于候选疾病的知识证据组织和辅助解释，不直接构成临床诊断结论。

## 3. 输入定义

### 3.1 候选疾病

候选疾病支持以下输入形式：

- 中文标准名称；
- 英文标准名称；
- HAM10000 疾病标签；
- 疾病实体编号；
- 复合疾病名称中的独立名称。

示例：

```text
基底细胞癌
Basal Cell Carcinoma
bcc
DIS_003
光化性角化病
表皮内癌
光化性角化病/表皮内癌
3.2 用户观察文本

用户观察文本用于提取语义锚点。

示例：

患者面部出现光亮的珍珠样结节，表面可见细小血管。

对应语义锚点：

LF_010 珍珠样结节
LF_011 表面毛细血管扩张
SITE_005 面部
3.3 检索参数

主要参数包括：

top_k
max_hops

其中：

top_k 表示最终返回的证据路径数量，默认值为 5；
max_hops 表示最大路径跳数，当前支持 1 或 2。
4. 图谱路径检索
4.1 一跳路径

一跳路径直接从候选疾病实体出发。

路径形式：

候选疾病 → 关系 → 证据实体

示例：

基底细胞癌 → 表现为 → 珍珠样结节
基底细胞癌 → 表现为 → 表面毛细血管扩张
基底细胞癌 → 常见于 → 面部

一跳路径属于候选疾病的直接知识证据，在排序中具有较高优先级。

4.2 受限二跳路径

二跳路径只允许通过“鉴别诊断”关系进行扩展。

路径形式：

候选疾病
→ 鉴别诊断
→ 鉴别疾病
→ 表现、部位、症状或检查
→ 证据实体

示例：

基底细胞癌
→ 鉴别诊断
→ 黑色素瘤
→ 表现为
→ 边界不规则

当前允许作为第二跳的关系包括：

has_manifestation
commonly_occurs_at
has_symptom
recommended_examination

该限制用于避免无约束图遍历产生大量低相关或重复路径。

5. 路径评分方法

路径总得分定义为：

total_score
= entity_match_score
+ relation_weight_score
+ disease_match_score
- path_length_penalty
5.1 实体匹配分

实体匹配分根据用户观察文本中识别出的语义锚点计算。

entity_match_score
= 语义锚点置信度 × 实体匹配权重

当前实体匹配权重为：

2.00

例如：

珍珠样结节置信度为 0.96
实体匹配分 = 0.96 × 2.00 = 1.92

如果路径终点没有对应的语义锚点，则实体匹配分为 0。

5.2 关系权重分

不同关系在疾病解释中的直接性不同，因此设置不同权重。

当前关系权重为：

has_manifestation: 1.50
commonly_occurs_at: 1.00
has_symptom: 0.90
differential_diagnosis: 0.80
recommended_examination: 0.60
has_risk_warning: 0.30
has_medical_advice: 0.20

一跳路径直接采用对应关系权重。

二跳路径中，最终一跳关系使用完整权重，前置的“鉴别诊断”关系采用折扣系数：

中间关系折扣系数 = 0.25

二跳关系权重分计算方式为：

最终关系权重
+ 中间关系权重 × 0.25
5.3 候选疾病匹配分

一跳路径直接描述候选疾病，疾病匹配分为：

1.00

二跳路径的最终证据属于鉴别疾病，因此仅获得部分疾病匹配分：

1.00 × 0.70 = 0.70

该设置用于防止鉴别疾病的间接路径排序高于候选疾病的直接证据。

5.4 路径长度惩罚

路径长度惩罚为：

一跳路径：0.00
二跳路径：0.35

该惩罚用于提升直接证据的排序优先级。

6. 排序规则

所有路径完成评分后，按照以下顺序排序：

总得分降序；
实体匹配分降序；
关系权重分降序；
路径跳数升序；
路径编号升序。

最终返回前 top_k 条路径。

7. 输出定义

每条排序路径至少包含以下信息：

path_id
rank
start_disease_id
start_disease_name
hop_count
end_entity_id
end_entity_name
end_entity_type
relation_chain
matched_anchor_ids
matched_anchor_names
matched_anchor_confidences
entity_match_score
relation_weight_score
disease_match_score
path_length_penalty
total_score
source_names
evidence_texts

该输出能够同时支持：

后端接口返回；
KG-RAG 提示词构造；
证据可追溯展示；
实验日志记录；
论文案例分析。
8. 典型排序案例

候选疾病：

基底细胞癌

用户观察：

患者面部出现光亮的珍珠样结节，表面可见细小血管。

排序结果：

Rank 1：珍珠样结节
总得分：4.42

Rank 2：表面毛细血管扩张
总得分：4.34

Rank 3：面部
总得分：3.92

其中：

珍珠样结节：
1.92 + 1.50 + 1.00 - 0.00 = 4.42

表面毛细血管扩张：
1.84 + 1.50 + 1.00 - 0.00 = 4.34

面部：
1.92 + 1.00 + 1.00 - 0.00 = 3.92

该结果表明，与用户观察直接匹配的皮损特征优先进入 Top-k，解剖部位证据次之。

验证脚本：

当前包含 6 组测试：

RANK_001 基底细胞癌典型证据排序
RANK_002 黑色素瘤典型证据排序

验证结果：

10. 证据不足处理

当用户观察文本没有识别出可靠语义锚点时，系统仍可返回候选疾病的基础图谱路径，但必须满足：

matched_anchor_ids 为空；
entity_match_score 为 0；
不得将未观察到的实体标记为直接匹配；
输出应被解释为候选疾病的一般知识证据，而不是用户个体证据。

例如：

皮损呈红色，但没有提供形态、部位和变化情况。

该文本不会仅根据“红色”强制映射到某个具体皮损实体。

11. 当前限制

当前版本存在以下限制：

语义锚点识别主要依赖标准名称和人工同义词表；
暂未使用向量相似度或大语言模型进行实体链接；
图谱路径最大深度限制为二跳；
二跳路径仅通过鉴别诊断关系扩展；
当前评分权重为规则设定，尚未通过训练数据学习；
当前排序结果不代表疾病概率；
当前系统不替代医生诊断和病理检查。
12. 后续扩展方向

后续可开展以下工作：

对关系权重进行消融实验；
对实体匹配权重进行敏感性分析；
比较一跳检索与一跳加二跳检索效果；
增加证据一致性和证据冲突标记；
增加来源可信度评分；
将 Top-k 路径接入 RAG 提示词模板；
建立批量实验日志与自动评价流程。
