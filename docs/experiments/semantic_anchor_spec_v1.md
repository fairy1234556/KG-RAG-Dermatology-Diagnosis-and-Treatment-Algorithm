# 语义锚点识别与实体映射规范 V1.0

## 1. 任务目标

将用户输入中的非标准皮肤病观察描述，映射为知识图谱中的标准实体。

例如：

- 脸上 → 面部
- 边缘不齐 → 边界不规则
- 多种颜色 → 颜色不均
- 细小血丝 → 表面毛细血管扩张

## 2. 数据文件

标准实体文件：

`kg/csv/entity_nodes.csv`

自定义同义词文件：

`kg/csv/entity_aliases.csv`

## 3. 支持的实体类型

当前语义锚点识别支持：

- Disease
- LesionFeature
- AnatomicalSite
- Symptom
- Examination

暂不从用户观察文本中识别：

- RiskWarning
- MedicalAdvice

## 4. 匹配顺序

V1.0 采用以下匹配方式：

1. 标准中文实体名称
2. 标准英文实体名称
3. entity_nodes.csv 中已有 alias
4. entity_aliases.csv 中的自定义口语别名

## 5. 匹配原则

- 优先匹配较长表达
- 同一个实体只保留最佳匹配
- 不允许一个同义词映射到多个实体
- 不对含义不明确的短词强制匹配
- 未匹配内容保留为证据不足信息

## 6. 当前边界

V1.0 为规则匹配版本，不包括：

- 大语言模型实体抽取
- 向量相似度匹配
- 模糊拼音匹配
- 自动术语扩展
- 临床诊断判断

## 7. 验收标准

- 七个代表性样例全部运行
- 典型口语描述能够映射到标准实体
- 证据不足样例不会被强制匹配
- 所有映射实体均存在于 entity_nodes.csv
